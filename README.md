# YouTube Cartoon Doctor Agent

GitHub-based automation foundation for Pakistani Urdu/Roman Urdu animated health-cartoon episodes.

Pipeline: Topic -> Script -> Safety Check -> Scene Plan -> Voice -> Video -> Metadata -> YouTube.

Characters:
- Ali: funny, energetic, curious male character.
- Dr. Sara: serious, professional female doctor with light witty responses.

Safety: educational entertainment only. No diagnosis, prescriptions, unsafe dosages, fake cures, or fearbait. Serious symptoms should be directed to a qualified healthcare professional.

V1 foundation: story engine, character bible, prompts, provider adapter structure, and GitHub Actions workflow.
